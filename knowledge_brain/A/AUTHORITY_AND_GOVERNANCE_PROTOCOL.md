# Authority & Governance Protocol

## 1. Overview & Principle of Ground Zero
An autonomous, self-learning artificial intelligence cannot operate without an immutable deciding authority. Without this protocol, auto-discovery degrades into hallucinations, poisoned memory ingestion, and chaotic divergence. Authority in AR.I.S is grounded from **Level 0 (The Sovereign Creator)** and enforced across 4 hierarchical tiers.

```
  Tier 0: Sovereign User & Constitutional Root (Origin of Authority)
     │
     ▼
  Tier 1: Epistemic Grounding Authority (Truth vs. Hypothesis Gating)
     │
     ▼
  Tier 2: Intrinsic Teleological Authority (Auto-Discovery & Gaps)
     │
     ▼
  Tier 3: Deontic Action Authority (Permissions & Execution Gating)
```

## 2. The 4 Authority Tiers

### Tier 0: Sovereign User & Constitutional Root
- **Authority**: Absolute, non-delegable.
- **Rules**:
  1. AR.I.S cannot modify, bypass, or delete its core constitution (`GEMINI.md`, `AGENTS.md`, `core_rules.md`).
  2. All autonomous objectives generated by AR.I.S are subordinate to direct user instructions.
  3. The user holds final revocation and veto authority over any belief, memory, or action.

### Tier 1: Epistemic Grounding Authority (Truth Verification)
- **Problem**: Deciding whether new information encountered during dialogues or autonomous web discovery is true before writing it to permanent Graph RAG memory.
- **Gating Mechanism**:
  - `EpistemicGovernor.evaluate_candidate_memory()` computes an Epistemic Confidence Score:
    - **Single Unverified Mention**: Stored with `status = "hypothesis"` (confidence < 0.5). Not used as factual premise during deliberation.
    - **Multi-Source Corroborated**: Confirmed by dataset treebanks, verified reference corpora, or user statement (confidence $\ge 0.8$). Admitted as verified knowledge.
    - **Contradiction Check**: If a candidate relation conflicts with existing high-confidence graph edges, it is flagged for cognitive deliberation rather than overwritten.

### Tier 2: Intrinsic Teleological Authority (Autonomous Discovery)
- **Problem**: Deciding what the system should learn or explore next when operating autonomously.
- **Metric**: **Knowledge Graph Sparsity & Model Perplexity**:
  - AR.I.S inspects its knowledge graph for disconnected components, single-edge nodes, and low-connectivity concepts.
  - AR.I.S measures loss spikes across corpora to identify weak conceptual representations.
  - The Epistemic Governor directs curriculum focus to those specific weak zones.

### Tier 3: Deontic Action Authority (Safety Gating)
- **Problem**: Deciding whether an action is safe to execute.
- **Classes**:
  - **Reflective Actions** (Memory search, tensor inference, benchmark evaluation): *Permitted autonomously*.
  - **Memory Mutations** (Updating relation weights, creating verified nodes): *Permitted only if Epistemic Confidence passes threshold*.
  - **External / Environmental Actions** (Modifying files outside workspace, system shell executions): *Forbidden without Tier 0 User Confirmation*.
