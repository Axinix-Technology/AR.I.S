# Generic Cognitive Architecture Principles

## Core Philosophy
AR.I.S is not a static script runner or a hardcoded workflow engine. It is an **Artificial Intelligent System**.

## Prohibited Patterns (Code-Based Orchestration)
- Hardcoded `if/else` ladders orchestrating complex domain workflows.
- Rigid, brittle state machines that break when an unforeseen input is encountered.
- One-off glue scripts that solve only today's scenario while adding technical debt to tomorrow.

## Preferred Patterns (Cognitive Generalization)
- Empower the AI's internal reasoning, self-reflection, and contextual evaluation.
- Design extensible, modular tools, prompts, interfaces, and cognitive loops that can handle arbitrary domains.
- Provide clean abstractions that allow the brain to make dynamic decisions rather than forcing it through predetermined code paths.
