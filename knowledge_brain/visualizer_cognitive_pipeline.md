# AR.I.S — Real-Time Cognitive Pipeline Visualizer

## Overview

The **Real-Time Cognitive Pipeline Visualizer** is a real-time observation and debugging interface that illuminates every stage of AR.I.S cognition as it reasons through a natural language query in real time.

---

## Architectural Principles (Rule 4 Compliance)

1. **Zero Added Procedural Orchestration**: The visualizer is a **pure observation layer**. It never drives, injects, or hardcodes reasoning decisions. It executes `ArisBrain.reason()` and observes the intermediate cognitive representations already generated by Tiers 1 through 7.
2. **Deterministic Stage Extraction**: The endpoint `/api/brain/trace/` captures snapshot data across the 8 pipeline stages:
   - **Stage 1 (Raw Ingestion)**: Query text, character boundaries, word count.
   - **Stage 2 (Lexical Tokenization — Tier 1)**: Deterministic character slices, token types (`word`, `number`, `symbol`), and positional coordinates.
   - **Stage 3 (Candidate Entity Spans — Tier 2)**: Dynamic multi-token sequences, compounds, and capitalized candidate spans.
   - **Stage 4 (Relational Binding — Tier 3)**: Subject → Relation → Object directional triples without hardcoded dictionary lookups.
   - **Stage 5 (Epistemic Assessment)**: Structural goal equation appraisal (`KNOWN`, `DERIVABLE`, `ACQUIRABLE`, `UNSUPPORTED`) and capability deficit matching.
   - **Stage 6 (Capability & Dispatch)**: Autonomous dispatch to neural classifier, relational traversal, or executable capability tool.
   - **Stage 7 (Graph Traversal & Retrieval)**: Symbolic graph path discovery, memory node matches, and belief verification.
   - **Stage 8 (Answer Synthesis & Natural Language Realization)**: Realizes human-understandable natural language sentences via `ArisResponseLearner`, with epistemic confidence, provenance, and execution timings.

## Endpoint Specifications

### 1. Web Visualizer Dashboard
- **URL**: `/visualizer/` (and `/api/visualizer/`)
- **Method**: `GET`
- **Response**: Renders `api/templates/aris_visualizer.html` — a dark-mode interactive dashboard with live presets, speed controls, sequential stage animation, and a raw JSON trace inspector.

### 2. Cognitive Trace API
- **URL**: `/api/brain/trace/`
- **Method**: `POST`
- **Payload**: `{"query": "<natural_language_query>"}`
- **Response**:
```json
{
  "query": "Who leads Axinix Technologies Development Team?",
  "answers": ["Ajay"],
  "stages": [
    { "stage_id": "input", "title": "Raw Query Ingestion", "data": { ... } },
    { "stage_id": "tokens", "title": "Lexical Tokenization (Tier 1)", "data": { ... } },
    { "stage_id": "candidates", "title": "Candidate Entity Spans (Tier 2)", "data": { ... } },
    { "stage_id": "bindings", "title": "Relational Binding (Tier 3)", "data": { ... } },
    { "stage_id": "epistemic", "title": "Epistemic State Assessment", "data": { ... } },
    { "stage_id": "decision", "title": "Capability & Operation Selection", "data": { ... } },
    { "stage_id": "retrieval", "title": "Graph Traversal & Fact Retrieval", "data": { ... } },
    { "stage_id": "answer", "title": "Cognitive Answer Synthesis", "data": { ... } }
  ],
  "full_result": { ... }
}
```
