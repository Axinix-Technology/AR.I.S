# Universal Agent Directives — AR.I.S

All AI assistants and autonomous agents operating in this workspace must strictly adhere to the following non-negotiable rules:

1. **Zero Hard Patches**: Address and resolve root causes. Never mask symptoms with temporary hacks or bypasses.
2. **Alphabetically Indexed Knowledge Brain**: Keep all architectural knowledge, updates, and solutions logged in `knowledge_brain/` and indexed alphabetically in `knowledge_brain/INDEX.md`.
3. **Knowledge Brain Pre-Verification**: Always inspect existing entries in `knowledge_brain/` before designing or implementing any requirement.
4. **Generic Intelligence (No Code-Based Orchestration)**: AR.I.S is an Artificial Intelligent System. Strengthen dynamic, generic cognitive abilities rather than hardcoding procedural orchestration pipelines.
5. **Mandatory Implementation & Audit Plan**: Every modification must have an explicit implementation plan and audit proof before execution.
6. **Human-Understandable Language**: Maintain transparent, intuitive, plain-language documentation and code explanations.
7. **Prohibition of Surface Guards & Mandatory Exact-Line Audit**: Never use character-level punctuation checks (e.g., `.endswith("?")`, `.startswith()`), string-slicing guards, or hardcoded stopword/keyword lists. All linguistic classifications must come from the neural tensor substrate (`CognitiveLinguisticFrame`). Every code edit must explicitly record and audit the exact file, exact line numbers, what changed, and why it changed.
